# Publish this package

1. Create a free account at https://github.com/signup and verify the email address.
2. Create a **public** repository named `afterecho-source-movement`.
3. Upload the contents of this folder at the repository root, preserving `src`, `tests`, `tools`, and `docs`. The included README and MIT license are already prepared.
4. Do not upload the surrounding workspace, `AfterEchoRoblox/backup`, game assets or downloaded tool binaries.

Suggested description:

Suggested topics: `roblox`, `luau`, `character-controller`, `movement`, `game-development`.

The repository is not published just because these files exist locally. Confirm the public URL after uploading.
